# ADR 003：权限先于检索，执行依据与参考知识分离

## 决策

有限合成语料采用显式字段过滤和关键词检索。服务端固定项目、工厂、产品族权限；客户端只选择查询词、材料、版次、零件、单位、币种和资料类型。客户端不提供权限项目或执行文件路径。

检索可以展示授权范围内的过期、未批准或不适用资料，但必须返回 `REFERENCE_ONLY` 与拒用原因。`history` 永远不能执行；即使材料相同、版本批准，其历史价格也不参与计算。

实际计价通过 `Knowledge.resolve` 唯一选择 catalog/template/rate。三类资料均须适用、获批、在有效期内、指向白名单制造载荷，且版本匹配。零或多个候选都拒绝；模型与浏览器不能指定绕过筛选的候选。

## 快照与失效

草案包含选中记录快照与工艺路线。依赖指纹覆盖制造文件 SHA-256 和选中知识记录；批准及导出重新解析当前依赖。撤销批准、变更范围或参考文件会令旧草案失效。未选中的历史记录变化不影响当前报价。

权限和业务适用性分开：无权记录不返回；有权但不适用的记录可作为参考。计价路径加载一次制造载荷，使用同一份内存快照判断候选与计算；文件级变更仍需在开发/受控发布时完成，不构成跨文件事务。

## 取舍

当前 12 条示例无需引入向量数据库。关键词命中不代表语义相关度，不报告检索召回率。真实试点数据增加后可加入混合检索，但权限过滤和执行选择仍由确定性规则控制。

没有知识发布审批后台、完整企业 IAM、自动变更通知或不可变制品库。本地演示令牌公开；不能以该模拟方式对外部署。后续设计见执行 roadmap。
