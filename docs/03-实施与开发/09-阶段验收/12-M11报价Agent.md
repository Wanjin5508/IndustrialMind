# M11 · 报价 Agent 验收

独立报价 Agent 从工程请求和混合附件开始。模型选择下一步工具，后端校验工具权限、字段依据和业务前置条件。工程师补件后可以继续原任务，审批人继续使用工作台的既有审批和同步入口。见 [[docs/03-实施与开发/08-工程决策/06-Agent运行循环]]。

| 验收项 | 证据 |
|---|---|
| 冻结回放 | 8/8 通过，两次隔离执行的结果与轨迹 8/8 一致。需要问人的结果与预期 8/8 一致。平均 7.75 步 |
| 权限与注入 | 一例恶意附件诱导模型提出批准。网关拒绝，批准、导出与 ERP 写入实际执行数为 0 |
| 正常报价对照 | Agent 和固定流程都为 100 件生成 €2,547.00 的草案 |
| 真实模型联调 | DEV-001 完成 10 步，生成 €2,547.00 内部草案、回复草稿并完成交付复核。DEV-003 在 5 步内查到 PLM 发布 B 版，记录错版风险并等待答复，未生成报价 |
| 异常路径 | 缺图时记录具体补件问题并续跑。错版停在工程复核。来源超时重试一次，仍失败则升级。初次抽取不足时通过聚焦页恢复。批准材料目录多解时等待人工 |
| 恢复 | 模拟进程在字段提交后退出。租约到期后读取已保存的工具选择，复用既有抽取写入，工程任务版本保持一致 |
| 现有流程回归 | M7 本地报价正例 4/4、预期阻断 8/8、知识 12/12、故障 6/6。M9 模拟集成 17/17 |

回放以脚本化模型测试工具网关和恢复行为，token 为脚本用量，模型费用未知。真实模型的原生函数调用与报价结果另用合成样例联调。评测配置见 [冻结场景](../../../evals/frozen/m11/scenarios.json)，报告见 [回放结果](../../../evals/results/m11/local.json)。

默认 API 启动时隐藏 Agent。设置 `RFQ_AGENT_ENABLED=1` 后重启，工程师侧栏出现「报价 Agent」。现场见 [[docs/05-面试与问答/09-选项B现场演示流程#先展示报价 Agent]]。
