5. 检查任务入口桌面布局；浏览器未捕获 error 级控制台日志。

## 边界

- 文本不会自动分类，显式选项是当前被验收的路由方式。
- SQLite 人工暂停可以恢复；进程在 EXTRACTING 中崩溃后的自动回收、超时注入和有界重试是 M6。
- 受控知识返回查询时快照；生产身份、动态租户授权、撤权后历史快照清理尚未实现。
- 审图完成不等于图纸获得工程批准或可以制造；也不比较客户 RFQ 要求。
- 没有真实 ERP/PLM/MES 写入，也没有冻结客户评测或收益实测。
