# ADR 002：证据强度与模型费用记录

## 问题与决策

模型能引用一个存在的来源 ID，同时给出该来源不支持的事实。M3 将来源存在、值受支持、定位粒度和人工确认拆开记录。`ReviewedField` 与 `EvidenceCheck` 为可导出 Pydantic 契约；输入长度受限、未知标记统一转为 null。

| 状态             | 含义                   | 处理              |
| -------------- | -------------------- | --------------- |
| TEXT_VERIFIED  | 同文档、正确标签和值匹配         | 可进入业务规则校验       |
| MISSING        | 未提供可用值               | 必须补充            |
| INVALID_SOURCE | 不在当前任务、错误文档类型或无效页号   | 阻断，不伪造可点来源      |
| TEXT_MISMATCH  | 来源存在，但不支持字段/值        | 阻断，要求工程复核       |
| AMBIGUOUS      | 同一文档标签有不同值           | 阻断，不按首个/最后一个值选择 |
| VISUAL_REVIEW  | PDF 页图存在，但无文本能验证视觉事实 | 页级回查，人工确认后继续    |

数字格式 `80` 与 `80.00` 在尺寸证据比对时等价；不做单位换算、材料近似或数量截断。RFQ 数量仍须满足正整数输入契约。文本依据校验不代表完整几何或制造可行性验证。

人工修正保留原值、原始证据状态、操作者、原因和时间，不将人工结论改写为“原文验证成功”。旧任务没有 M3 证据字段时 UI 显示历史记录，重新抽取才产生新证据状态；不静默改写历史。

## 页图粒度

本阶段不生成推测坐标。PDF 文本行仍对应页级定位，扫描件只能回到实际 PNG 页图，UI 可打开原尺寸图。`bbox` 如有值必须为合法归一化矩形；当前解析器始终返回 null。区域定位需要后续真实坐标提取及独立验证。

## 配置、异常与费用

后端验证服务 URL（远端 HTTPS，无嵌入凭据）、1–300 秒有限超时及不同角色令牌。失败只记录稳定错误码、模型、服务主机和耗时；不持久化供应商原始错误正文、密钥或完整请求。

模型费用与制造报价分别管理。`config/model-pricing.json` 是有来源、核对日期、复核期限和 hash 的模型费率快照；只适用于匹配的模型与服务主机。使用 Decimal 计算 `(未缓存输入 × 输入费率 + 缓存输入 × 缓存费率 + 输出 × 输出费率) / 1,000,000`。reasoning tokens 已包含在输出里，不重复收费。

当前采用 DeepSeek 公布的高峰费率估算，实际低峰扣费可能更低，不宣称为账单；费用单位 USD，制造报价为 EUR，两者不相加。费率过期、模型不匹配或 usage 缺失则保留未知。每次成功响应保存费率快照而非只保存可变配置路径。

## 后果与边界

保守阻断会增加人工工作，但能避免来源“看似存在”造成的误信。受控知识检索、多入口编排、自动重试和租约恢复仍属于 M4–M6；三个真实开发样例不代替 M7 冻结评测。
