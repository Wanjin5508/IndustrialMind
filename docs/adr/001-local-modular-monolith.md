# ADR-001：本地模块化单体与确定性核心

Status: Accepted · Owner: Engineering · Date: 2026-11-08 · Milestones: M0–M2

## 背景

一个候选人需要交付可检查的 RFQ 工作台。数据是合成样例，尚无企业系统权限或已配置模型凭据；范围以已确认 roadmap 为准。

## 决定

Next.js + TypeScript 前端，FastAPI + Pydantic 后端，SQLite 保存任务快照和审计事件。模型仅用于抽取，服务负责校验、Decimal 计价、审批和版本失效。以显式状态机实现，不引入多 Agent 自由循环。

持久化变更使用事务与乐观版本检查。当前为单用户本机演示，角色令牌提供后端操作区分，不宣称企业身份认证。服务默认绑定 loopback；正式上线需单独身份、租户、安全、容量和运维设计。

## 影响与替代项

相比微服务和队列，部署简单且便于演示。处理长文档的吞吐、分布式 worker 和生产权限属于后续里程碑。LangGraph 等可在 M5 后按明确需要替换内部实现，不能同时维护两套权威状态。

## 验证

独立验证价格、持久化、过期写入、审批失效、冲突阻断、权限边界、真实文件抽取与前端闭环。真实模型调用单独记录，离线成功不替代该验收。
