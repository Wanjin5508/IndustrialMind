# 核心版本演示步骤

> [!note] 当前演示入口
> 本文保留 M0–M2 核心流程。现场排练及后续里程碑的讲解见 [[docs/05-面试与问答/01-演示讲稿]]。

本文是核心操作清单。完整讲稿及商业假设见 [[docs/05-面试与问答/01-演示讲稿]] 和 [[docs/02-方案与规划/05-商业论证]]。

1. 打开任务总览，说明全部资料是合成数据，选 DEV-001。
2. 选择 LOCAL_TEXT 或已配置的 LIVE，点击开始抽取。明确说明当前模式，不能把本地文本解析说成视觉模型能力。
3. 点击材料字段的「依据」，展示原文和 PDF 页图。说明来源是页级定位。
4. 计算内部预算：100 件单价 25.47 EUR，总价 2,547.00 EUR。展开人工、材料、一次性 setup 摊销与受控版本；交期等未确认事项清楚可见。
5. 切审批人，确认工程事项并填写备注，批准后生成、下载内部草案；查看追加的审计事件。
6. 切回工程师，在资料页把数量确认成 500，并填写客户澄清依据。旧草案和审批立即失效；重新计算总价为 12,255.00 EUR，仍需重新审批。
7. 选择 DEV-003 展示 A/B 版冲突。填写原因并上传 `fixtures/dev/drawings/PM-BRKT-010_B.pdf`；替换后重新抽取才可继续。
8. 选择 DEV-004，展示材料未知、不能直接报价；说明需要客户澄清，而不是猜材料。

演示重点：工程判断有证据，变更会传播到价格与审批，模型不能越过确定性规则。上述能力的实测范围见 [[docs/03-实施与开发/09-阶段验收/01-M2报价闭环]]。
